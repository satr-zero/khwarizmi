# دليل صياغة رسائل البريد الإلكتروني الرسمية

عندما يُطلب منك كتابة أو صياغة رسالة بريد إلكتروني رسمية أو مهنية، التزم بالقواعد الصارمة التالية:

1. **الافتتاحية والتحية:**
   - ابدأ دائماً بالتحية الرسمية التالية:
     "السلام عليكم ورحمة الله وبركاته،
     تحية طيبة وبعد،"
   - إذا كان اسم أو منصب المستقبل معروفاً، وجه الخطاب إليه مباشرة (مثلاً: "سعادة المدير العام الأستاذ/ ... المحترم").

2. **هيكل الرسالة:**
   - **السطر الافتتاحي:** اذكر الغرض من المراسلة بوضوح ودون إطالة (مثلاً: "يطيب لي التواصل معكم بخصوص...").
   - **المتن:** اكتب التفاصيل في نقاط مختصرة ومرتبة منطقياً.
   - **الدعوة للإجراء (Call to Action):** حدد المطلوب أو الخطوة القادمة بوضوح وتحديد زمني إن وجد.

3. **الخاتمة والتوقيع:**
   - اختتم الرسالة دائماً بالعبارة الرسمية:
     "شاكرين ومقدّرين حسن تعاونكم،
     وتفضلوا بقبول فائق الاحترام والتقدير."
   - أضف خانة توقيع افتراضية:
     [الاسم]
     [المسمى الوظيفي]
     [بيانات الاتصال]
