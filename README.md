## 🤖 ما هو خوارزمي؟

خوارزمي تطبيق سطح مكتب يضع نموذج لغوي كبير (LLM) داخل **حلقة وكيل (Agent Loop)**
كاملة: يستقبل طلبك، يستدعي الأدوات المناسبة (قراءة ملفات، بحث ويب، طرفية،
متصفح...)، يعرض كل خطوة حيّاً في المحادثة، ثم يقدّم النتيجة النهائية.

ما يميّزه عن واجهة محادثة عادية:

- **تنفيذ مستقل حقيقي**: للمهام الكبيرة يبني خطة من خطوات ذرية، يعرضها
  لاعتمادك بزر «تنفيذ بوضع الكود»، ثم ينفّذها خطوة بخطوة مع حفظ تقدّم
  كل خطوة في قاعدة البيانات (Checkpoint) — فلا يضيع العمل عند الانقطاع.
- **ميكانيكية بث بأسلوب opencode**: لا يُقتل البث الصامت أبداً — النماذج
  الضخمة قد تصمت دقائق وهي تعمل على الخادم، فينتظرها النظام مع نبض
  إحاطة حي («الخادم يعالج منذ X ثانية»)، والحماية الوحيدة سقف مطلق
  (10 دقائق) + زر الإيقاف اليدوي.
- **شريط حالة واعٍ بالطور**: يخبرك ماذا يفعل النموذج فعلاً — يفكّر، يكتب،
  ينفّذ أداة، أو صامت لأن الخادم يجهّز الرد — لا مزيد من «انتظر الرد» الأعمى.
- **ذاكرة دائمة**: يتذكر الحقائق عنك عبر الجلسات (مع بحث دلالي).
- **يعمل عربياً بالكامل**: واجهة RTL وخطوط عربية (IBM Plex Sans Arabic).

## ✨ الميزات

### 💬 محادثة الوكيل
- بث حي للردود (SSE) مع عرض التفكير الموسّع، استدعاءات الأدوات، ونتائجها.
- حارس «الوعد بلا تنفيذ»: يكشف وعود النموذج اللفظية المتكررة دون استدعاء
  أداة، فيعترضها ويعيد توجيه النموذج للتنفيذ العملي تلقائياً.
- إعادة محاولة تلقائية للبث المنقطع (Exponential Backoff) مع بانر عدّ تنازلي.
- تعديل رسائل المستخدم وإعادة الإرسال، إيقاف التوليد، سجل محادثات محفوظ.

### 🧭 أنماط البرمجة الخمسة
| النمط | الدور |
|---|---|
| **مدير** | تنسيق المهام وتوجيهها للأداة/المسار الصحيح |
| **تخطيط** | تحليل وتقسيم لخطوات ذرية — قراءة فقط |
| **كود** | تنفيذ الخطوات المعتمدة: كتابة، تعديل، أوامر |
| **إصلاح أخطاء** | تشخيص وإصلاح مركز لأخطاء التنفيذ |
| **استفسار** | شرح وتحليل آمن — قراءة فقط إطلاقاً |

تصفية الأدوات تُطبَّق فعلياً حسب النمط النشط، والانتقال لوضع الكود يتم
تلقائياً عند اعتماد خطة (مع رسالة اعتماد تلقائية في المحادثة).

### 🗺️ التنفيذ المستقل Plan-and-Execute
- مخطط (Planner Node) يفكك الهدف إلى ≤ 20 مهمة فرعية ذرية.
- بطاقة خطة تفاعلية: تقدّم حي، حالات كل خطوة، زرّا اعتماد/إلغاء.
- عند فشل خطوة نهائياً: يسألك «متابعة / إعادة / إلغاء» بدل إجهاض كل شيء.
- تنفيذ الأدوات بمهلة ديناميكية لكل أداة مع إلغاء فعلي عند انتهائها.

### 🧠 الذاكرة الدائمة
تخزين حقائق (`store_memory`) واسترجاع دلالي (`search_memory`) يُحقن
تلقائياً في سياق المحادثات اللاحقة — sqlite محلي بالكامل.

### 📁 وكيل المشاريع البرمجية
- فتح مشروع → خريطة بنية تُحقن في السياق (تُغني عن استكشاف متكرر).
- قراءة/بحث/تعديل عبر `read_project_file` و`search_project_code`.
- اقتراح التعديلات كبطاقات Diff تفاعلية بانتظار موافقتك قبل أي كتابة.
- `run_terminal_command` مع بوابة أمان للأوامر الخطرة + إلغاء يقتل شجرة العمليات.

### 🌐 وكيل المتصفح
تصفح حي (`browse_url`)، نقر وملء حقول، فحص بصري للصفحة، تنزيل ملفات —
مع حاجز أمان يعترض إجراءات الدفع/الحساسة حتى تأكيدك الصريح.

### 🧩 المهارات (Skills)
- **Sidecar Skills**: أدوات خارجية (مثل خادم Python) تُكتشف من
  `%APPDATA%\Khwarizmi\Skills`، تبدأ تلقائياً، وتُسجَّل كأدوات بعد موافقتك.
- **Text Skills**: أدلة إرشادية Markdown تُكتشف من `%APPDATA%\Khwarizmi\TextSkills`
  وتُحقن كفهرس خفيف ثم تُحمَّل عند الحاجة فقط.

### ⏰ المجدول والتذكيرات
تذكيرات (`schedule_reminder`)، إشعارات Windows، أيقونة صينية (Tray)،
وتشغيل تلقائي مع بدء Windows (قابل للضبط من الإعدادات).

### 🔌 المزوّدات المدعومة (12+)
Gemini، Claude، OpenAI، NVIDIA، OpenRouter، Groq، DeepSeek، Ollama،
LM Studio، vLLM، أي متوافق مع OpenAI (رابط مخصص)، ومزوّدون محليون مخصصون
— مع دعم التفكير الموسّع والتفكير التكيفي حيث يتوفر.

### 🔍 البحث
DuckDuckGo (احتياطي مجاني)، Brave، ومخصص — مع `fetch_url` لاستخراج
محتوى الصفحات (Jina Reader أساسياً + جلب مباشر احتياطياً عند تقييده).

### 🛡️ الأمان
- اعتراض إجراءات المتصفح المالية حتى التأكيد.
- تصنيف حساسية الأسئلة، بوابة أوامر الطرفية، sandbox للمشاريع.
- المفاتيح في مخزن آمن (SecureStorage) لا في الكود.

### 🪵 السجلات
نظام تسجيل موحّد (طرفية + ملف) بمعرفات ترابط لكل طلب — شغّل التطبيق
وراقب الطرفية لترى كل خطوة يمر بها الوكيل.

## 🏗️ كيف يعمل؟ (نظرة معمارية)

```
┌───────────── واجهة (Flutter + Riverpod) ─────────────┐
│ ChatScreen → ChatBubble → TaskPlanCard / Diff / HUD  │
└──────────────────────┬──────────────────────────────┘
                       │ ChatController (حلقة الوكيل)
        ┌──────────────┴──────────────┐
        │ Providers (SSE + إعادة محاولة) │
        │ StreamCollector + Watchdog  │  ← بث بلا قتل للصامت
        └──────────────┬──────────────┘
                       │ Tools (ToolRegistry + إلغاء)
        ┌──────────────┴──────────────┐
        │ TaskExecutionEngine         │  ← Plan-and-Execute + Checkpoint
        │ SQLite: tasks / plans /     │
        │ chat / memory / projects /  │
        │ skills / reminders          │
        └─────────────────────────────┘
```

- **طبقة التنفيذ الموحّدة** (`lib/core/execution/`): جامِع البث الوحيد
  لكل المزوّدين — لا استثناءات هاربة، كل فشل مصنّف، والنص الجزئي محفوظ.
- **المحرك المستقل** (`lib/features/agent/services/`): تخطيط → اعتماد →
  تنفيذ الخطوات → سؤال المستخدم عند الحاجة.
- **الأوضاع** (`coding_modes.dart`): تصفية الأدوات + توجيه سلوكي لكل نمط.

## 🚀 المتطلبات والتشغيل

### المتطلبات
- **Flutter SDK** (قناة stable) — `flutter --version`
- **Windows 10/11** (مُختبَر) أو Linux
- مفتاح API لأحد المزوّدات (Gemini / OpenAI / NVIDIA / Ollama المحلي...)

### التشغيل (وضع التطوير)
```powershell
flutter pub get
flutter run -d windows
```

### البناء للإصدار
```powershell
flutter build windows --release
# الناتج: build\windows\x64\runner\Release\khwarizmi.exe
```

### أول إقلاع
1. افتح ⚙️ الإعدادات → تبويب **النماذج والمزوّدون** → اختر المزوّد وأدخل المفتاح.
2. (اختياري) افتح مجلد مشروعك بزر 📁 فوق حقل الإدخال لتفعيل وضع الوكيل البرمجي.
3. جرّب مهمة كبيرة (مثل: «ابنِ لي لعبة...») → ستظهر خطة → اضغط **«تنفيذ بوضع الكود»**.

## ⚙️ الإعداد الأول (مفاتيح API والمجلدات)

- المفاتيح تُحفظ في مخزن النظام الآمن عبر شاشة الإعدادات (لا تُكتب في أي ملف).
- مجلد المهارات: `%APPDATA%\Khwarizmi\Skills\<اسم-المهارة>\manifest.json`
- مجلد المهارات النصية: `%APPDATA%\Khwarizmi\TextSkills\<الاسم>\SKILL.md`
- قاعدة البيانات: `%APPDATA%\...\Khwarizmi\khwarizmi_memory.db`
- صيغة `manifest.json` لأي Skill خارجي:
```json
{
  "name": "my_tool",
  "display_name": "اسم العرض",
  "description": "ماذا تفعل الأداة",
  "endpoint": "http://localhost:5055/execute",
  "input_schema": {
    "type": "object",
    "properties": { "city": { "type": "string" } },
    "required": ["city"]
  },
  "permissions": ["network"],
  "start_command": "python sidecar.py"
}
```

## 🩺 استكشاف الأخطاء الشائعة

| العرَض | التفسير والحل |
|---|---|
| النموذج يصمت دقائق أثناء مهمة ضخمة | **سلوك طبيعي**: يولّد على الخادم دفعة واحدة — راقب نبض «الخادم يعالج منذ X ثانية» ولا تقتله |
| «انقطع الاتصال (10 دقائق)» | اتصال ميت فعلاً — تحقق من الشبكة أو جرّب موديلاً أخف |
| `fetch_url` يرجع `via: direct_fetch_fallback` | خدمة Jina المجانية مُقيَّدة مؤقتاً — جُلبت الصفحة مباشرة، لا مشكلة |
| «وعد متكرر بالتنفيذ دون أداة» | الحارس اعترض رداً لفظياً وأعاد التوجيه — إن تكرر، وضّح طلبك أو بدّل الموديل |
| خطوة خطة فشلت وسألك «متابعة/إعادة/إلغاء» | أجب بكلمة واحدة؛ «إعادة» تعيد الخطوة الفاشلة فقط |
| `Skipping folder without manifest.json` عند الإقلاع | مجلد مهارة ناقص في `%APPDATA%\Khwarizmi\Skills` — أضف `manifest.json` أو احذف المجلد |
| بطء أول استجابة (time-to-first-token) | طبيعي مع السياقات الضخمة (خريطة مشروع + ذكريات) — العدّاد يعرض الثواني |
